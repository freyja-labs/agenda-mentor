---
title: Type the board
description: The whiteboard's layout with a keyboard in place of the marker, for a remote session or a room with no board.
---

Run the session from the [run sheet](../index.html#run-sheet) on one shared screen, with this page open in the faculty member's browser: the board saves there and goes to their prompt builder. The faculty member types everything, the challenger's questions included, and the facilitator asks the questions and keeps time.
